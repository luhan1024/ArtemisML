# tests

该目录保存 ArtemisML 的自动化测试。

## 测试原则

测试应覆盖公共 API 的可观察行为，而不仅是内部实现细节：

## 新增组件测试模板

新增 loss 必须测试已知数值、Mean/Sum 缩放、解析 gradient 与有限差分、空输入、形状错误、
非有限值和不可导点。新增 model 必须测试 `fit(X,y)`、显式 optimizer、预测/评价、未训练
状态、重复 fit、维度错误、标签编码、保存加载 round-trip，并验证失败后状态不被破坏。

测试文件放在对应层级目录，测试目标注册到 CMake；不得只测试内部成员或用空测试表示未实现。
所有构建、CTest 和可执行程序运行由程序员0在 WSL `zsh` 中串行执行。

- 合法输入的数值结果和形状。
- 空数据、维度错误、非有限值和未训练状态。
- 异常类型及错误边界。
- 重复训练、失败后状态和 Pipeline 数据流。
- 算法公式与已知结果的一致性。

测试在 WSL 的 CMake/CTest 中串行运行，不能与其他线程同时占用 `build-wsl`。
