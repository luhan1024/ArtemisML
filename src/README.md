# src

该目录保存 ArtemisML 公共头文件对应的实现。

## 实现约定

- 每个实现文件应与 `include/art` 下的公共接口保持路径和命名空间一致。
- 算法实现不得通过未声明的公共符号绕过 API 规范。

## 新增组件实现模板

实现一个新的 loss 时，先在 `include/art/loss` 声明 `LossFunction`，再在本目录对应层
实现公式、缩放、输入校验和数值稳定性；实现文件不得改变公共接口或偷偷依赖具体模型。
实现一个新的 model 时，先完成 `base` 协议适配，再实现默认 fit、显式 optimizer fit、
predict/evaluate、状态检查和持久化；训练循环由模型负责，优化器只执行单步更新。每项
实现必须有对应 `tests/<layer>` 验收，并同步更新三处 README。
- 参数检查、状态转换和错误类型必须与头文件协议一致。
- 修改源码后，按照 AGENTS.md 在 WSL 中完成串行构建与测试。

实现层只负责行为，不重新定义数据模型和跨层职责。新增模块应同步增加对应测试和 README。
